自动化流水线（无人核实）

数据可信度分级

每条产品数据都标注核验状态，访问者可一眼分辨数据可靠程度：

多源核验一致 ≥2 个独立来源（官方 + 测评）参数一致
官方来源确认 品牌官网产品页参数一致
来源冲突待复核 不同来源参数不一致，等待下一轮复核
种子数据待核验 初始数据，等待流水线自动核验
待核验 尚未取得有效来源

品牌真实性如何确认

  1. 每个品牌配置官网域名（初始为公开常识级候选）；
  2. 流水线访问官网首页，校验 HTTP 状态与页面标题 / og:site_name 是否包含品牌名（中/英文）；
  3. 匹配成功 → 标记「已核验」并记录证据；无官网候选的品牌由搜索引擎自动发现官网；
  4. 匹配失败或无法访问 → 如实标记「待人工确认 / 核验失败」，绝不冒充已核验。

部署（所有人可访问）

  1. 将本仓库推送到 GitHub（公开仓库）；
  2. Settings → Pages → Source → GitHub Actions；
  3. 推送后 Actions 自动构建并发布到 https://<用户名>.github.io/<仓库名>/；
  4. 定时同步工作流会自动运行全链路并提交数据更新，网页随之自动刷新。

路线图

  • 品牌专属解析器：适配 JS 渲染官网与隐藏 API（如部分中国品牌官网）；
  • 价格监控：接入电商公开数据，自动记录价格曲线；
  • 用户投稿：开放提交新品与参数纠错，进入核验队列；
  • 图片：自动抓取官方产品图并归档。
